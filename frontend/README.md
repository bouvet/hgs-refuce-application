# frontend

Next.js 16 app for the HGS Refuce Application. See the project's
[`CLAUDE.md`](./CLAUDE.md) for frontend-specific conventions (Tailwind v4, shadcn/UI, Better Auth,
Next.js 16 breaking changes).

Full documentation, including project structure, authentication, the data layer, and styling, lives
at **[bouvet.github.io/hgs-refuce-application/frontend/](https://bouvet.github.io/hgs-refuce-application/frontend/)**.

```bash
npm install
npm run dev   # http://localhost:3000
```
