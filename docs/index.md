# HGS Refuce Application

Documentation for the HGS Refuce Application — a waste/refuse tracking system for a local Bouvet office.

The project has two parts:

- **Backend** — Python + FastAPI + SQLAlchemy (SQLite locally, PostgreSQL in production)
- **Frontend** — Next.js, TypeScript, Tailwind CSS, shadcn/UI

Use the navigation on the left to browse the documentation.
