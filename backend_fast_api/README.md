# hgs-refuce-application
An application that tracks the refuce from a local Bouvet office. Made primarly with LLM.

to run
```
# Powershell
\.venv\Scripts\activate.ps1

# CMD
\.venv\Scripts\activate.ps1

#Unix
\.venv\Scripts\activate
```
```
uvicorn src.hgs_refuce_app.main:app --reload --port 8010
```
